# Lumioo Mobile

Lumioo Mobile é a versão mobile da plataforma Lumioo, desenvolvida utilizando React Native com Expo. O objetivo é proporcionar uma experiência otimizada para dispositivos móveis, permitindo que estudantes, professores, pesquisadores e profissionais da academia compartilhem, descubram e interajam com trabalhos acadêmicos de forma prática e acessível.

## Sobre o Projeto

Assim como a versão web, o Lumioo Mobile visa conectar a comunidade acadêmica, facilitando o acesso a projetos científicos, pesquisas universitárias e a construção de uma rede de contatos profissionais. A interface será adaptada para dispositivos móveis, mantendo as principais funcionalidades da plataforma web.

## Tecnologias Utilizadas

- [React Native](https://reactnative.dev/)
- [Expo](https://expo.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- Outras bibliotecas do ecossistema React Native

## Funcionalidades Previstas

- Cadastro e autenticação de usuários
- Feed de trabalhos acadêmicos
- Visualização de detalhes de projetos e perfis
- Curtidas, comentários e salvamento de posts
- Chat e mensagens diretas
- Exploração de projetos e busca avançada
- Perfil do usuário e edição de informações

## Como Executar o Projeto

1. Certifique-se de ter o [Node.js](https://nodejs.org/) e o [Expo CLI](https://docs.expo.dev/get-started/installation/) instalados.
2. Clone este repositório.
3. Acesse a pasta `mobileclient`.
4. Instale as dependências:
   ```bash
   npm install
   ```
5. Inicie o projeto:
   ```bash
   npx expo start
   ```
6. Escaneie o QR Code com o aplicativo Expo Go no seu dispositivo móvel ou utilize um emulador.
